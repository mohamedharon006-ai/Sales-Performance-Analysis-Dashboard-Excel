# Sales Analytics & Business Insights Using Excel

## 📊 Project Overview

This project presents an interactive sales dashboard built using Microsoft Excel to analyze sales performance and generate meaningful business insights.

The dashboard provides an overview of key sales metrics, product categories, regional performance, and sales trends over time. It also includes interactive filters that allow users to explore the data from different perspectives.

## 🎯 Project Objectives

- Analyze overall sales performance and key business metrics.
- Identify the top-performing product categories and sub-categories.
- Compare sales performance across regions, cities, and states.
- Explore customer purchasing behavior.
- Track sales and quantity trends over time.
- Provide interactive filtering for data exploration.

## 📈 Dashboard Features

- **Sales KPIs:** Total Sales, Net Sales, Returns, Discounts, COGS, Total Customers, and Total Orders.
- **Category Analysis:** Compare sales across Furniture, Office Supplies, and Technology.
- **Regional Analysis:** Analyze sales across different regions.
- **Geographical Analysis:** Identify top-performing cities and states.
- **Sub-Category Analysis:** Explore sales distribution across product sub-categories.
- **Time-Based Analysis:** Monitor sales and quantity trends over multiple years.
- **Interactive Filters:** Filter results by city, salesperson, return status, and product category.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Data Analysis
- Pivot Tables and Pivot Charts
- Interactive Dashboards
- Data Visualization

## 💡 Business Value

This dashboard transforms sales data into visual insights that help users monitor business performance, compare regional sales, and identify top-performing product categories.

It demonstrates the use of Excel for business intelligence, sales analysis, and data-driven decision-making.
